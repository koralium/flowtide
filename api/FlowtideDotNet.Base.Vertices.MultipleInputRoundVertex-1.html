Remarks

Watermarks, locking events and initial data done events are synchronized across the inputs as in MultipleInputVertex<T>. A round holds only messages that were queued ahead of the next event of another kind, so no message is taken past a watermark, a checkpoint or a trigger. With MaxRoundMessages at one the vertex calls OnRecieve(int, T, long) per message.
