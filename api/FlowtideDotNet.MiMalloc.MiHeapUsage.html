Struct MiHeapUsage

Namespace
FlowtideDotNet.MiMalloc

Exact committed-versus-live accounting obtained by walking a heap's pages. Unlike MiMallocStats this does not depend on any thread merging its statistics: the walk enumerates every page of the heap regardless of which thread currently owns it.
