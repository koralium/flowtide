LiveStatsMerged

True when the live-allocation figures were folded up from the thread-local heaps before this snapshot was taken. When false, LiveNormalBytes, LiveHugeBytes and Pages only contain whatever threads happened to have merged already, and are typically near zero — they do NOT mean "nothing is allocated".

RetainedBytes

Committed bytes not currently handed out as live blocks: free blocks inside pages plus committed-but-unused page space. A large and growing value relative to CommittedBytes indicates fragmentation or retention.

Null when LiveStatsMerged is false, because it cannot be computed from unmerged live figures. For an exact value that never depends on merging, use GetHeapUsage().
