Remarks

Names and examples use Flowtide SQL. Square brackets in signatures mark optional arguments; they are not literal SQL. Extension signatures, type declarations and required options describe Substrait bindings, not additional SQL arguments. The Flowtide notes and constraints apply to each listed profile. Aggregate, window and table functions are separate capabilities.

COUNT(*)

The zero-argument binding counts rows. The one-argument native binding counts non-null values, but ordinary SQL COUNT(x) is currently rejected by the SQL planner; SQL accepts COUNT(*) and COUNT(DISTINCT x). Empty input returns Int64 zero. The DISTINCT form uses the separate count_distinct binding.

  • Extension signatures: count:any, count:
  • Extension source: extension:io.substrait:functions_aggregate_generic
  • Extension type declaration: (any) -> i64; nullability=DECLARED_OUTPUT
  • Extension type declaration: () -> i64; nullability=DECLARED_OUTPUT
  • Required Substrait option overflow: SILENT
  • Aggregation phase: INITIAL_TO_RESULT
  • Sql count expression: false
  • Supports filter: true

string_agg(x, separator)

The separator must be a string literal. Null input values are ignored; values are concatenated in ascending Flowtide string order, retaining duplicates. No contributing values yield null. The current implementation also yields null if all strings and the separator are empty. User-supplied aggregate ORDER BY and SQL DISTINCT are rejected.
